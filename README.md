# Nexora para Windows y macOS

Instaladores y actualizaciones firmadas de Nexora · Control de cajas y tesorería.

La versión publicada se descarga desde [Releases](https://github.com/Meth0ds/Nexora-releases/releases/latest). Los instaladores son para Windows x64 y macOS Apple Silicon. El código fuente se mantiene en un repositorio privado.

Las [notas de la 1.5.2](notas/1.5.2.md) describen la próxima versión. El canal de actualizaciones continúa sirviendo la versión publicada.
